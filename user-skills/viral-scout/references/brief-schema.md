# Brief Schema (consumed by ugc-video-auto)

`brief.json` aggregates all per-video analyses into a single document.

```json
{
  "theme": "string",
  "theme_slug": "string",
  "run_id": "YYYY-MM-DD-HHMM",
  "generated_at": "ISO8601",
  "candidate_count": 5,
  "candidates": [
    {
      "rank": 1,
      "source": {
        "platform": "youtube",
        "url": "https://...",
        "author_handle": "@...",
        "views": 1200000,
        "posted_at": "ISO8601"
      },
      "hook": {
        "text": "...",
        "type": "pergunta",
        "first_3s_breakdown": "..."
      },
      "structure": {
        "framework": "F.A.L.A.R.",
        "sections": [...]
      },
      "visual": {
        "shot_types": [...],
        "cuts_per_30s": 12,
        "b_roll": "...",
        "text_overlay": "..."
      },
      "cta": "...",
      "viral_hypothesis": "...",
      "transcript_excerpt": "first 500 chars for context",
      "ugc_recreation_brief": {
        "suggested_hook_pt": "adapted hook in PT-BR",
        "script_skeleton": "outline of script for avatar recreation",
        "shot_list_suggestion": [...],
        "duration_target_s": 45
      }
    }
  ]
}
```

## Field notes

- `rank` is by view count descending after filtering.
- `ugc_recreation_brief` is generated by a second Claude pass during `brief.py` — adapts the original to the avatar pipeline format. This is the part `ugc-video-auto` consumes.
- `transcript_excerpt` is included so downstream tools have raw context without re-reading files.
